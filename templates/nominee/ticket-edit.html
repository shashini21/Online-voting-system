Editing Guidelines
What You Can Edit
• Subject (title)
• Description (problem details)
• This helps improve support responses
What You Cannot Edit
• Ticket ID (auto-assigned)
• Creation date
• Status (handled by support)
• Support responses
Editing Limits
• Only OPEN tickets can be edited
• Once resolved, tickets are locked
• Prevents disruption of support workflow
Best Practices
• Be specific about the issue
• Include steps to reproduce
• Mention what you've already tried
• Keep descriptions clear and concise
